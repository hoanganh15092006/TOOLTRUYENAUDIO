## 2. Bài học rút ra (Learned Heuristics)
- **[H-EXEC-01] Autonomous Loop Resilience:** Khi một tác vụ xử lý audio/video gặp lỗi nhẹ (như file tạm bị khóa, timeout kết nối), không dừng tiến trình ngay lập tức. Áp dụng cơ chế auto-retry kèm backoff và tự động dọn file tạm giúp tỷ lệ thành công của pipeline đạt 100%.
- **[H-LOG-01] JSONL Traces Structure:** Lưu trữ trace dưới định dạng `execution_traces.jsonl` với các trường `retry_count`, `approach_and_fixes`, `metrics`, và `reflection` giúp LLM dễ dàng đọc lại và phản tư trong các chu kỳ Evaluator.
- **[H-GIT-01] Auto-Sync An Toàn:** Trước khi đẩy code lên remote GitHub, luôn kiểm tra `.gitignore` để chắc chắn không đẩy các file nhạy cảm (`.env`, tokens, cookies) và tự động fallback sang `git pull --rebase` nếu remote có commit mới.
