## 📌 Quy chuẩn cấu trúc mỗi bản Devlog
Mỗi bản ghi Devlog được tự động sinh ra và gồm 4 phần tiêu chuẩn:
1. **Bối cảnh & Vấn đề thực tế (Context):** Vấn đề gặp phải và số lần thử nghiệm thực tế.
2. **Bài học rút ra (Learned Heuristics):** Những kinh nghiệm, thuật toán hoặc mẹo vừa kiểm chứng.
3. **Thay đổi kỹ thuật (Changelog & Technical Improvements):** Danh sách hàm mới / logic sửa đổi trong tool.
4. **Benchmark & Hiệu năng:** So sánh định lượng trước và sau khi tối ưu.
